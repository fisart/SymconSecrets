Configuration & backup

Configuration import / export

Hardware trust settings saved or imported in the console are staged. They become active only after this exact operation is approved. Provisioned storage and frontend bindings cannot be replaced through ordinary settings.

Both new modules have console export/import controls. Configuration contains paths and settings; it excludes vault contents, private keys, administrator credentials, cookies and setup codes.

Imported modules remain disabled. Check instance references, the HTTPS origin and storage locations before enabling them.

Central configuration backup

The integration package describes both new module IDs, schemas and configuration fields. The current backup module requires an explicit reviewed registry entry. Until that registration is accepted, it must not report these instances as covered.

Configuration backup is not a backup of the vault or its external keys. Use Recovery for the native encrypted vault backup and reviewed value restore, and Peers for optional synchronization. Real deployment and migration acceptance remain pending.

Operating guide

First-time setup: steps 1–5

  1. In the Secrets Frontend console, enter your trusted HTTPS address if requested and click Step 1: Open setup.
  2. In the browser, click Prepare first passkey and follow your device’s prompt.
  3. Keep the browser open. In the console, click Step 3: Refresh approval requests, compare all four identifier groups, and click the matching Step 3: Approve. Return to the browser; it checks automatically.
  4. In the browser, review the suggested backend, storage and optional connections. Click Review setup plan. Confirm storage persistence or permissions if asked.
  5. Check the summary, click Set up and sign in, and confirm with your passkey.

If the result is uncertain after you confirm, use Resolve accepted setup in the console; do not begin a second setup.

Using Secrets

Select a location, then browse the folders on the left and their contents on the right. Single-click to select. Double-click a folder to open it or a secret to show its value while signed in. If a hardware-key policy protects viewing, confirm with that key. Use Hide values to clear visible secrets. Values also hide after 30 seconds. Use New folder and New secret to create items, and Back or Up one level to navigate. On touch screens, select a folder and choose Open folder. Lists and other data types can be managed in the advanced editor.
