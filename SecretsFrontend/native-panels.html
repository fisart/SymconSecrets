Recovery

Encrypted backup

Download an encrypted copy of this vault or restore secret values from a saved backup. Keep its recovery key separately. Lost administrator access is recovered from the sign-in page or Access & keys.

Complete encrypted backup

The backup contains the authenticated vault state, permissions, audit, pending jobs, keys and captured uncertain provider completions. A generated recovery key is shown separately after passkey approval. Store the file and recovery key separately.

Earlier encryption generations stay available for committed snapshots. Replacing a compromised vault identity uses a fresh vault and reviewed recovery.

Recover values from a backup

Uploads are bounded and authenticated. Recovery keeps this vault’s current administrators, permissions and peer identities. A local copy is the default. Replacing current values requires exact review and may publish a new global revision to active peers.

Compaction keeps the latest 512 mutation outcomes and audit entries. Pending jobs, uncertain effects and receiver cursors are retained. Old unknown operations must never be automatically replayed.

Standalone cannot detect a consistent restoration of all trusted files without an independent current reference. File synchronization and atomic markers do not certify physical power-loss durability or a Docker backup configuration.

Create a machine capability

Choose a record in Secrets to prefill its scope and path. Read-only is the default. The generated token is shown once after passkey approval and never enters settings exports.

Symcon API

Use the generated token with SECB_ReadNativeSecret or SECB_WriteNativeSecret. Writes require the current revision, a monotonically increasing sequence and a stable operation UUID. Revoked or out-of-scope tokens are rejected at the storage boundary.
